# VMHardeningChecklistTool
This script will asses the security posture of a local Windows 11 Virtual Machine and produce a readable output file that details what all is checked on the VM.
The following will be checked:
1. Windows Version & Build Number
2. System Uptime / Last Boot Time
3. Hostname & Domain Status
4. Windows Update Service Status
5. Pending Updates Detected
6. Automatic Updates Enabled
7. Windows Defender Firewall Enabled
8. Firewall Default Inbound Policy
9. Network/IP Connections
10. Listening Ports Enumeration
11. Local Accounts Identified
12. Guest Account Status
13. Password Complexity Policy
14. Account Lockout Policy
15. Windows Defender Antivirus Status
16. Real-time Protection Enabled
17. Security Event Logging Enabled
18. Log Retention Configuration
